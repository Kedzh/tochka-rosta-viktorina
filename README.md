# Викторина «Что ты знаешь о Точке роста?»

Ко Дню рождения ЦОЦ и ГП «Точка роста». 22 вопроса, первые 3 места — памятные призы.

🌐 **Сайт:** https://kedzh.github.io/tochka-rosta-viktorina/
📱 Работает на телефоне, планшете и проекторе. Интернет нужен только при первом открытии —
дальше страница сохраняется в память телефона и работает офлайн.

## Как запустить

### На компьютере / проекторе

Откройте **`index.html`** двойным щелчком (или с GitHub Pages по ссылке выше).
Включите **полноэкранный режим** — `F11`.

### На телефоне

1. Откройте ссылку, нажмите в меню браузера **«Добавить на главный экран»**
   (в Safari: значок «Поделиться» → «На экран Домой»).
2. Викторина запустится как отдельное приложение, без адресной строки.
3. Работает без интернета после первого открытия.

### Ход викторины

1. На титульном экране нажмите **«Начать викторину»**.
2. Каждый участник вводит **фамилию, имя и класс**, потом отвечает на 22 вопроса.
3. После викторины — экран результата, потом **«Таблица результатов»**: там подиум 1–3 места
   с памятными призами и список всех участников. Кнопка **«Распечатать»** делает таблицу на А4.

Работает **полностью офлайн**, интернет не нужен. Интернет не требуется ни на одном шаге.

### Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Выбрать ответ | клавиши `1`–`9` или мышь | тап по варианту |
| Проверить / дальше | `Enter` или `→`, или кнопка внизу экрана | кнопка внизу экрана |
| Начать викторину | `Enter` | кнопка |

### Экраны

- **Титульный** — приветствие, правила, кнопки.
- **Регистрация** — фамилия-имя + выбор класса.
- **Вопрос** — номер, прогресс-бар, счёт, варианты ответа.
  Вопросы с несколькими ответами помечены зелёной подсказкой.
- **Проверка** — правильный вариант подсвечивается зелёным, ошибка — красным,
  появляется всплывающее пояснение. Ответы скрыты, пока не нажата кнопка.
- **Результат** — счёт «N из 22», место, похвала.
- **Таблица результатов** — подиум + все участники, печать.
- **Ключ ответов** — правильные ответы и пояснения (для учителя), можно распечатать.

Результаты сохраняются в браузере (`localStorage`). Кнопка **«Очистить всё»** удаляет их
перед новым мероприятием.

## Правка вопросов

Все вопросы лежат в начале файла, в массиве `QUESTIONS`. Формат:

```js
{
  type: 'single',            // single | multi (несколько верных) | neg (несколько НЕверных)
  q: 'Текст вопроса',
  o: ['вариант 1', 'вариант 2', 'вариант 3'],
  a: [0],                    // индексы правильных вариантов в массиве o
  exp: 'Пояснение, всплывает после ответа.'
}
```

Индексы считаются с нуля. После правки просто обновите файл в браузере — `Ctrl+F5`.

## Технические детали

- Один HTML-файл, всё внутри. Внешних библиотек нет — интернет не нужен.
- Service worker кэширует страницу и картинки при первом открытии.
- Результаты участников лежат в `localStorage` браузера — на сервер ничего не уходят.
- Адаптивная вёрстка: 360×640, 390×844, 844×390 (альбомная), планшет, проектор 1080p и 4K.
- `user-select: none` и `touch-action: manipulation` — чтобы случайно не выделялся текст
  и не срабатывал двойной-тап зум.
