# Функция для Yandex Cloud — приёмник результатов

Викторина отправляет результат сюда, функция дописывает строку в Яндекс.Таблицу.

## Зачем нужна эта прослойка

GitHub Pages — статический сайт, своего сервера у него нет. Писать в Яндекс.Таблицу
из браузера нельзя: нужен секретный ключ, а всё, что есть в коде страницы, читает любой
посетитель через «просмотр кода». Функция на сервере держит ключ у себя и никому его не показывает.

## Что делает функция

1. Получает IAM-токен сервисного аккаунта через служебный адрес `169.254.254.254`
   (ключи хранить не нужно — они не в коде).
2. Находит первую свободную строку на листе.
3. Дописывает туда результат.

## Переменные окружения

| Переменная | Пример | Назначение |
|---|---|---|
| `TABLE_ID` | `1a2b3c4d5e6f7g8h` | идентификатор таблицы |
| `SHEET` | `Лист1` | имя листа |
| `FIRST_DATA_ROW` | `2` | первая строка под шапкой |
| `API_VERSIONS` | `v3,v2,v4` | какие версии API перебирать |

Идентификатор таблицы виден в её ссылке:
`https://yandex.ru/table-1a2b3c4d5e6f7g8h/edit` → `1a2b3c4d5e6f7g8h`.

## Собранные данные

| Дата и время | Класс | Участник | Баллы | Максимум | Время (сек) | Время прохождения |
|---|---|---|---|---|---|---|
| 09.10.2026 14:30 | 6 | Иванов Артём | 22 | 22 | 143 | 2 мин 23 сек |

## Установка — по шагам

1. Создайте в Яндекс.Таблицах документ, в первой строке сделайте заголовки как в таблице выше.
2. В [console.cloud.yandex.ru](https://console.cloud.yandex.ru) создайте **сервисный аккаунт**
   (например `viktorina-writer`), выдайте ему права на работу с документами и привяжите
   к таблице («Поделиться» → доступ для этого аккаунта).
3. Создайте **Cloud Function**:
   - среда выполнения: Python 3.12
   - сервисный аккаунт: `viktorina-writer`
   - переменные окружения: `TABLE_ID`, `SHEET=Лист1`, `FIRST_DATA_ROW=2`
   - код: содержимое `handler.py`
   - зависимости: `requests==2.32.3`
4. **Включите CORS** в настройках функции («Вызывать функцию» / «Обзор HTTP» → добавить
   правило для `*`), иначе браузер не сможет слать результат.
5. Откройте адрес функции с `?check=1` — она покажет:
   - получен ли токен,
   - какая версия API отвечает.
   Если все три попытки вернули ошибку — пришлите мне этот текст, поправлю версию.
6. Скопируйте адрес функции и впишите его в викторину:

```js
const CONFIG = { submitUrl: 'https://ваша-функция.run.yandexcloud.net' };
```

## Самопроверка

`GET https://адрес-функции/?check=1` → JSON с диагностикой.

`GET https://адрес-функции/` → «Приёмник результатов работает.»

## Если что-то не работает

Викторина никогда не падает из-за сети: если приёмник недоступен, на экране появляется
строка результата с кнопкой «Скопировать» — её можно вставить в таблицу вручную.
