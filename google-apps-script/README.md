# Приёмник результатов → Google Таблица

Самый простой способ: без сервера, без ключей, без регистрации API. Бесплатно.

## Почему это работает

GitHub Pages — статический сайт, писать в таблицу из браузера он не может: нужна
секретная авторизация, а её нельзя спрятать в коде страницы. Apps Script решает это —
Google сам держит доступ к таблице, а наружу торчит только ссылка-приёмник.

Викторина отправляет данные в режиме `no-cors`, поэтому на стороне Google **не нужно**
ничего настраивать про CORS.

## Что приходит в таблицу

| Дата и время | Класс | Участник | Баллы | Максимум | Время (сек) | Время прохождения |
|---|---|---|---|---|---|---|
| 09.10.2026 14:30 | 6 | Иванов Артём | 22 | 22 | 143 | 2 мин 23 сек |

## Установка — 6 шагов

1. Создайте таблицу на [docs.google.com](https://docs.google.com).
2. **Расширения → Apps Script.**
3. Удалите содержимое `Code.gs`, вставьте код из `Code.gs` этой папки.
4. Впишите ID таблицы в строку `const SHEET_ID = '...'` — ID виден в ссылке:
   `https://docs.google.com/spreadsheets/d/1a2b3c4d5e6f7g8h/edit`
5. Вверху в Apps Script выберите функцию `setup` → **Выполнить**. Один раз дайте
   доступ — скрипт сам создаст шапку таблицы.
6. **Развернуть → Новое развёртывание → Веб-приложение → Доступ: Любой.**
   Скопируйте ссылку, которая заканчивается на `/exec`.

Готово. Ссылка вида
`https://script.google.com/macros/s/AKfyc..../exec`
вписывается в викторину:

```js
const CONFIG = {
  submitUrl: 'https://script.google.com/macros/s/AKfyc..../exec',
  corsMode: 'no-cors'
};
```

## Проверка

Откройте ссылку приёмника в браузере — должен появиться текст
«Приёмник работает. Ответов в таблице: 0».

Если вместо этого ошибка — проверьте, что таблица открыта **вашему** аккаунту
и ID скопирован полностью.

## Важно знать

- Ссылка приёмника — это фактически пароль: кто её знает, тот может дописывать строки.
  Для школьной викторины это нормально, но не публикуйте её на сайте вместе с кодом
  викторины — вставьте её в файл `index.html`, который и так лежит в репозитории.
  Если хотите закрыть: пересоздайте развёртывание и не показывайте ссылку.
- Строка **не проверяется на дубли**: если участник прошёл викторину дважды, будет
  две строки. Это удобно — видно, кто переписывал.
- Лимит Google generous: обычная викторина на класс укладывается с огромным запасом.
